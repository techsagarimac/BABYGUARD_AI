# Demo data

Put a short **presentation video** here if you do not have a baby for the live demo.

Suggested names:

- `demo_baby.mp4`
- `baby.mp4`
- `demo.mp4`

Then click **DEMO VIDEO** in the dashboard. If this folder contains exactly one video, it plays automatically (looping). If there are several files, a file picker opens.

Use a clip you are allowed to show in college: a royalty-free stock video of an infant in a crib, a video of a doll, or a recording of a student acting as the subject.

The live webcam still works. Click **LIVE** (or **START**) to go back to the camera.

BabyGuard AI does not record or upload video. Clips stay on this computer.
